# AI_USAGE.md

AI tools, primarily ChatGPT, were used throughout this project as a support resource for setup guidance, terminal commands, troubleshooting, evidence collection, and basic security concepts.

AI assistance was used to help:
- plan and run benign OpenClaw tasks;
- create and test the harmless `safe-marker` tool and local web lab;
- structure the direct and indirect prompt-injection experiments;
- organize the threat model, labels, and controls;
- identify and research a relevant OpenClaw security advisory;
- review report structure and wording;
- troubleshoot transferring evidence files from the VM to the host Mac.

All commands were executed and verified in the course VM. Experimental results, screenshots, audit logs, and evidence files were checked against the actual system behavior. AI-assisted writing was reviewed and revised before inclusion in the final submission to ensure true understanding. No real credentials or sensitive information were intentionally included in AI prompts or project artifacts.
